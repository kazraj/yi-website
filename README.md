# Young Innovators (YI)

Official website for Young Innovators (YI), a non-profit initiative that empowers young innovators by providing knowledge, resources, and a supportive community.

## Motto
"There Is No Box to Think Outside Of."

## Features
- Arabic and English versions
- Responsive design
- Multi-page website
- Community and contact pages
- Static website (no accounts or database)

## Technologies
- HTML5
- CSS3
- JavaScript

## Project Structure
ar/     - Arabic pages
en/     - English pages
css/    - Stylesheets
js/     - JavaScript files
assets/ - Images and logos
